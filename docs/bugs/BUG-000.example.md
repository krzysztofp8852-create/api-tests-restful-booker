## Summary

API accepts a booking whose `checkout` date is earlier than `checkin`. A hotel reservation with inverted dates should be rejected.

## Preconditions

- API is up (`GET /ping` → 201)

## Steps to reproduce

1. `POST /booking` with JSON:

```json
{
  "firstname": "Krzysztof",
  "lastname": "Tester",
  "totalprice": 50,
  "depositpaid": true,
  "bookingdates": {
    "checkin": "2026-09-10",
    "checkout": "2026-09-01"
  }
}
```

2. Observe status and body.

## Expected result

Client error (4xx). Body explains that checkout must be after checkin. No `bookingid` is created.
