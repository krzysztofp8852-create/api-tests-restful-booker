# BUG-003: Non-numeric totalprice is accepted and stored as null

| Field | Value |
|---|---|
| ID | BUG-003 |
| Title | String `totalprice` is coerced to null instead of rejected |
| Severity | Minor |
| Priority | P3 |
| Status | Open |
| Environment | Restful Booker · `https://restful-booker.herokuapp.com` |
| Endpoint | `POST /booking` |
| Found in | TC-019 |
| Date | 2026-08-13 |
| Author | Krzysztof Pabich |

## Summary

Sending `"totalprice": "abc"` still creates a booking (**200**). The field is stored as `null` instead of rejecting the type error.

## Preconditions

- API is up (`GET /ping` → 201)

## Steps to reproduce

1. `POST /booking` with JSON:

```json
{
  "firstname": "Krzysztof",
  "lastname": "Tester",
  "totalprice": "abc",
  "depositpaid": true,
  "bookingdates": {
    "checkin": "2026-09-01",
    "checkout": "2026-09-05"
  }
}
```

## Expected result

HTTP **400**. Body states that `totalprice` must be a number. No `bookingid`.

## Actual result

- HTTP status: **200**
- Body (trimmed):

```json
{
  "bookingid": 547,
  "booking": {
    "firstname": "Krzysztof",
    "lastname": "Tester",
    "totalprice": null,
    "depositpaid": true,
    "bookingdates": {
      "checkin": "2026-09-01",
      "checkout": "2026-09-05"
    }
  }
}
```

## Evidence

- [x] Reproduced at least twice: yes
- [x] Date/time of reproduction: 2026-08-13
- Covered by Newman: `TC-019 POST Create booking — totalprice as string`

## Workaround

Send only numeric `totalprice` from the client.

## Notes

Silent coercion to `null` can hide client bugs and produce bookings without a price.
